# План разработки прототипа — Smash Figesh (CanonGame)

> Для агента-исполнителя. Диздок: `design/gdd.md`, решения: `design/decisions.md`,
> референсы: `design/references/` (вид от стрелка, пушка снизу, конструкция впереди).
> **Приоритет — играбельность механики. Графика — базовые примитивы (цветные боксы/сферы), никакой генерации арта.**

## Целевой результат

Играбельный прототип в `scenes/main.pix3scene`: тап по экрану → пушка стреляет ядром в
точку прицела → 3D-физика сносит башню из блоков → сбил всех «королей» до исчерпания
выстрелов = победа, иначе поражение. 2 тестовых уровня подряд.

## Этапы (каждый — играбельный инкремент, проверять play_start + game_run)

### 1. Сцена и камера
- Портретный вьюпорт (см. `pix3project.yaml`).
- Камера за пушкой: низко, смотрит слегка вверх на арену; земля-плоскость, свет уже есть.
- Пушка = примитив (цилиндр/бокс) внизу по центру экрана, чисто визуальная.

### 2. Физика и башня
- Использовать встроенную физику движка (см. `.claude/skills/pix3-game-dev/references/nodes-and-systems.md` — какие узлы/компоненты физики есть; НЕ писать свою физику, если есть готовая; если готовой rigid-body физики нет — минимальный собственный интегратор box-физики только тогда).
- Земля — статическое тело. Башня — пирамида из динамических боксов (примитивы, 2–3 цвета).
- Блоки-«короли» — выделенный цвет (красный), 2–4 шт в конструкции.
- Критерий: башня стоит стабильно, при толчке рассыпается каскадом.

### 3. Стрельба и прицел
- Тап/драг по экрану → raycast/проекция в мир → пушка доворачивается, по отпусканию — выстрел сферы-ядра с импульсом.
- Ядро — динамическое тело, живёт ~5 сек или до остановки, потом удаляется.
- Критерий (game_run): выстрел сдвигает блоки (nodeMoved), ядро появляется (nodeAppeared).

### 4. Правила уровня
- GameState-скрипт: выстрелы (например 5), список живых «королей», % снесённых блоков (блок «снесён», если упал с исходной позиции больше порога или улетел за арену).
- «Король» считается сбитым при падении/сильном ударе.
- Победа: все короли сбиты → звёзды по % (1★ факт, 2★ ≥60%, 3★ ≥90%). Поражение: выстрелы = 0, короли живы.
- Зарегистрировать GameDebugProvider (score/shots/kingsLeft/destroyedPct) — для верификации через game_run.

### 5. HUD и цикл
- HUD: счётчик выстрелов, «короли: N», % разрушения (Label2D).
- Оверлей победы/поражения: звёзды текстом, кнопки «Дальше»/«Ещё раз» (Button2D).
- 2 уровня: данные башни (раскладка блоков + короли + число выстрелов) в конфиге/скрипте; «Дальше» грузит второй, после второго — снова первый.

### 6. Сочность (минимум, без арта)
- Тряска камеры при попадании, punch-scale HUD, процедурные SFX (`scene.audio.sfx`: 'explosion', 'score', 'win', 'lose').
- Ядро оставляет лёгкий эффект (масштаб/вспышка) — только встроенный juice, без частиц-арта, если дорого.

## Верификация (обязательна после каждого этапа)
- `compile_scripts` → `play_start` → `read_errors`.
- game_run: выстрел по башне → `gameStateChanged shots by -1`, `nodeMoved` блока; добить королей → `gameState kingsLeft eq 0`; негативный контроль тапа (control.tap в пустую зону).
- `play_stop` в конце каждой сессии проверки.

## Вне рамок прототипа
Спец-снаряды, особые блоки (бочки, укреплённые), карта уровней, экономика, финальный арт, музыка.
