# {{PROJECT_NAME}}

A Pix3 project that is still at the **idea stage**: a design document and its references, and no
game yet. The genre skeleton — scenes, scripts, a playable loop — is expanded into this same project
when you press **Start prototype**, so nothing here is thrown away.

## Project structure

- `design/gdd.md` — the design document. This is the idea; everything agreed on lands here.
- `design/decisions.md` — settled forks, one line each, so nothing is decided twice.
- `design/source/` — documents you attached, kept verbatim for reading by section.
- `references/` — reference and moodboard images, with roles in `references/index.json`.
- `scenes/main.pix3scene` — an empty Full HD canvas, a placeholder until the recipe arrives.
- `AGENTS.md` — rules and pointers for AI agents working on this project.

Sprite, script and audio folders appear when the prototype needs them.

## Getting started

1. Talk the idea through in the chat next to the document — the document is the record.
2. Ask for moodboards when you reach the look; the candidates land in `references/`.
3. Press **Start prototype** when the idea is worth building.
