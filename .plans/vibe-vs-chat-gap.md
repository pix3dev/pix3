# Замер разрыва: Vibe против one-shot HTML/JS в чате

**Зачем.** Эталон пользователя сформулирован прямо: «играбельный прототип уровня того, как мы
в чате Клода или Гемини просим сделать html/js страничку-игру». До сих пор мы мерили Vibe
**против себя** (§11.8/§11.9 [prompt-to-playable-flow.md](prompt-to-playable-flow.md): 55→26
обращений к модели, 459→145 с). Head-to-head против самого эталона не проводился ни разу,
поэтому порядок работ (покрытие / темп / шеринг) выбирался по интуиции. Этот документ — протокол
и журнал такого замера.

**Что решает результат.** Какой из трёх рычагов идёт первым:
покрытие (идея вне каталога рецептов), темп (минуты против секунды), шеринг (ссылки нет).

---

## 1. Две ланы

| | Чат-лана (эталон) | Vibe-лана |
| --- | --- | --- |
| Что | один запрос → одностраничный HTML/JS | промпт → стадия идеи → прототип на движке |
| Как исполняется | `POST /v1/messages` на `pix3-agent-bridge` (лана Claude Code MAX), **без тулов** — то есть честный one-shot, как в чате | редактор в браузере, обычный путь пользователя |
| Модель | одна и та же семья; фиксируется в журнале прогона | та, что выбрана в редакторе; фиксируется |
| Артефакт | `.html` в `.plans/measurements/chat/` | проект Vibe + Download HTML |

Ланы **специально** несимметричны по механике — сравниваем не архитектуры, а то, что получает
пользователь за своё ожидание.

## 2. Промпты

Два внутри покрытия рецептов (есть исторические замеры) и два заведомо вне каталога —
там Vibe падает в `recipe-blank-2d`, и это худший, но частый случай.

| # | Промпт | Покрытие Vibe |
| --- | --- | --- |
| P1 | тапалка про монетки | `recipe-tapper-2d` — внутри (замер §11.8) |
| P2 | змейка | `recipe-arena-2d` — внутри (замер §11.9) |
| P3 | флоппи-бёрд | вне каталога (runner-рецепт спроектирован, не написан) |
| P4 | тетрис | вне каталога (grid-puzzle рецепта нет) |

Промпт даётся **дословно одинаковый** в обе ланы, без уточнений и без подсказок про жанр.

## 3. Метрики

**Время (главное — что видит пользователь):**

- `t_first` — до первого кадра, в который можно ткнуть.
- `t_done` — до состояния, которое не стыдно показать (есть цель и проигрыш/победа).
- В Vibe дополнительно: обращений к модели, модельное время, контекст в конце, число ходов.

**Результат — рубрика, 0/1/2 по пяти пунктам (максимум 10):**

| Пункт | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Запускается | ошибки в консоли / чёрный экран | работает с артефактами | чисто |
| Кор-луп | нет | ввод меняет состояние | ввод → состояние → счёт/прогресс |
| Условие конца | нет | есть проигрыш **или** победа | есть и рестарт |
| Отклик (сочность) | ничего | что-то одно (звук/твин/частицы) | три и больше |
| Подача | дефолтный белый | читаемо | связная палитра + HUD + шрифт |

Оценку ставит один и тот же судья по обоим артефактам подряд, чтобы шкала не поехала.

### Чат-лана

Прогон 2026-08-28, `claude-sonnet-5` через `pix3-agent-bridge` (лана MAX, тулы не переданы ⇒
честный один ход). Промпт дословно: «сделай html/js страничку — игру: <идея>».

| Промпт | t_done | Строк | Синтаксис | Что есть в коде |
| --- | --- | --- | --- | --- |
| P1 тапалка | 32.5 с | 321 | OK | счёт, localStorage-рекорд, градиент, тень, шрифт |
| P2 змейка | 31.4 с | 323 | OK | счёт, проигрыш, рестарт, localStorage, моб. ввод, градиент/тень/шрифт |
| P3 флоппи | 35.1 с | 324 | OK | счёт, проигрыш, localStorage, моб. ввод, градиент/тень/шрифт |
| P4 тетрис | 44.1 с | 486 | OK | счёт, проигрыш, рестарт, градиент/тень/шрифт |

**Среднее время до артефакта — 36 с, один ход, без единого уточняющего вопроса.**
Артефакты: `measurements/chat/*.html` (+ сырые ответы `*.json`).

Рубрику по этим четырём **ещё не ставили**: пункты «запускается» и «кор-луп» требуют реального
запуска в браузере, а не чтения кода. Пока зафиксировано только то, что проверяется статически
(`node --check` по извлечённому JS + наличие механик в исходнике).

**Три наблюдения уже сейчас:**

1. **Ни в одной из четырёх нет ни звука, ни частиц** (`AudioContext`/`particle` не встречаются).
   Весь «вау» чат-ланы — статическая косметика: CSS-градиент, `box-shadow`/`text-shadow`,
   заданный шрифт, и в трёх из четырёх — рекорд в `localStorage`. Это ровно тот вывод, который
   [done/flow-wow-t0.md](done/flow-wow-t0.md) сделал аналитически («~70 % их вау — статическая
   косметика»); теперь он измерен, а не заявлен. Для нас это хорошая новость: наш вау-пол
   T0 бьёт по площадке, где эталон слаб (сочность), и должен держать площадку, где эталон
   силён бесплатно (подача первого кадра).
2. **Порог входа у эталона — ноль ходов**: одна генерация, никаких вопросов, никакой стадии
   идеи. Всё, что мы ставим ДО первого играбельного кадра, тратит бюджет против эталона,
   который тратит 36 с.
3. **Побочно, дефект моста:** `usage.output_tokens` для agent-SDK-ланы возвращает 2–8 при
   ответе на 8–12 КБ — то есть учёт токенов этой ланы неверен. Отдельный мелкий баг, на замер
   не влияет (время меряем по стене), но на любые расчёты стоимости — влияет.

**Мусор, который пришлось выкинуть:** первые два ответа лана отбила (`stop_reason: refusal`)
и пожаловалась на кодировку — русский промпт ехал к модели через bash-argv покорёженным.
Лечится тем, что запрос собирается и отправляется целиком из Python с явным UTF-8
(`measurements/chatlane.py`). На случай повторения: refusal на безобидном промпте — сначала
проверить, что дошло до модели, а не списывать на классификатор.
